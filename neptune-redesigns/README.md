# Neptune Chat Concepts

Open `index.html` in a browser to see Blue Current as a full-screen chat. Use the top-right sliders control to choose among fourteen Neptune themes; the arrow keys also switch themes when focus is outside a control. The theme menu stays closed by default so the first screen follows the reference layout.

Open `history-panel-ideas.html` to compare fifteen complete navigation-panel redesigns in the Portfolio Spectrum palette. Use the sliders button in the top-right to switch studies; each one rethinks the branding, create/search controls, and history model.

Every theme shares T3 Chat’s clean composition: a 252px conversation rail, spacious chat canvas, left-aligned prompt area, and low-profile bottom composer. Each design changes the palette and planetary atmosphere while preserving the same screen geometry. The fourteen visual directions are:

1. **Blue Current** — deep ocean blue with a banded planet mark.
2. **Triton Ice** — glacial cyan over ink blue.
3. **Great Dark Spot** — near-black storm tones with a distant planetary shadow.
4. **Ringed Horizon** — cool indigo with fine orbital ellipses.
5. **Methane Blue** — atmospheric bands and a striped planet mark.
6. **Aurora Drift** — restrained blue-green polar glow.
7. **Moonlit Neptune** — graphite surfaces and silver-blue details.
8. **Voyager Signal** — sparse stars and Voyager 2 coordinates.
9. **Deep Orbit** — saturated indigo and a soft planetary halo.
10. **Ice Giant** — frosted light surfaces with Blue Current’s Neptune blue accents.
11. **Studio Mint** — portfolio graphite, mint focus, lilac orbital details, and a gold action.
12. **Lilac Orbit** — portfolio lilac over deep ink, with mint orbital highlights.
13. **Peach Comet** — portfolio peach and gold accents over Neptune’s deep-space blue.
14. **Portfolio Spectrum** — mint, lilac, gold, and peach as quiet interface signals.

Starter prompts and the composer show local sample replies only; the previews do not call Neptune’s backend.
